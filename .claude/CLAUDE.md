# sukashi

LLMテキストの意味空間型電子透かし（SemStamp流）のスクラッチ実装。
文埋め込み空間を鍵由来のLSH超平面で領域分割し、文単位の棄却サンプリングで透かしを入れる。
パラフレーズ攻撃への耐性がトークン空間型（旧実装、git履歴に残存）との違い。

## コマンド

- 依存同期: `uv sync`
- ユニットテスト（モデル不要・合成埋め込み）: `uv run pytest`

## 構成

- `src/sukashi/semstamp.py` — LSH分割・文単位棄却サンプリング生成・z検定検出のすべて
- 生成デモには因果LM（Sarashina2.2-3B等）と文埋め込みモデル（ruri-v3-30m等）が必要

## 規約

- Python は uv 管理（brew の python を使わない）
- コード・テスト内の文字列は英語のみ（日本語プロンプトを使うデモはリポジトリ外に置く）
- コミットに生成物マーカーやセッションURLを入れない
